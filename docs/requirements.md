# B2B Order Management Platform

## 1. Project Purpose

This project is a B2B Order Management Platform for a simulated distributor.

The system will manage products, carts, orders, invoices, stock status and admin controls.

## 2. Target Users

- Admin
- Customer

## 3. Main Features

- User authentication
- Role-based access
- Product management
- Product browsing
- Shopping cart
- Order management
- Invoice management
- Stock status
- Admin controls
- REST API integration
- Validation and error handling
- Activity records

## 4. Technology Stack

- Frontend: React
- Backend: Node.js
- Database: PostgreSQL
- Authentication: JWT
- Containerization: Docker

## 5. Project Goal

The goal is to develop a working and reviewable full-stack application that allows users to manage products, carts and orders while providing administrative controls.

## 6. Success Criteria

- Users can log in successfully.
- Users can view products.
- Users can add products to a cart.
- Users can place orders.
- Users can view order information.
- Stock information can be managed.
- Admin users can manage the system.
- Invalid inputs are handled properly.
- Unauthorized users cannot access restricted features.
