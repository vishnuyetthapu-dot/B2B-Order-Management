B2B Order Management Platform

Project Overview

The B2B Order Management Platform is a full-stack web application designed to manage products, inventory, and customer orders for a simulated distributor.

Technology Stack

- Frontend: React.js, CSS
- Backend: Node.js, Express.js
- Database: PostgreSQL
- API: REST API

Features Implemented

- View product listings
- Add, update, and delete products through backend APIs
- Store product and order data in PostgreSQL
- Shopping cart interface
- Order creation logic with product quantity validation
- Order status update API
- Inventory stock update logic

Project Structure

- "frontend/" — Frontend application
- "backend/" — Server and API logic
- "docs/" — Project requirements
- "package.json" — Project configuration

Setup

1. Install Node.js and PostgreSQL.
2. Configure database credentials in the backend ".env" file.
3. Install the required dependencies.
4. Start the backend server.
5. Start the frontend development server.

Project Status

This project is under development. Order placement and end-to-end functionality are still being tested.
